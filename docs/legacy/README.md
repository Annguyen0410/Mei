# Legacy Documentation (Archived)

These documents describe **old releases** of the app (LiteBrowser 2.0 / 3.0 era, before the
Mei rebrand) and are kept for historical reference only. They were written in Vietnamese; the current codebase is documented
in English in the following files at the repository root:

- **`README.md`** — features, architecture, data flow, slash commands, build (current)
- **`ARCHITECTURE.md`** — layers, storage, extension points, roadmap (current)
- **`RUN_AND_BUILD.md`** — how to run from source and build the desktop `.exe` (current)

Nothing in the current code reads or depends on the files below.

| File | Era | What it is |
|---|---|---|
| `FEATURES.md` | 2.0 | Legacy feature & architecture document (superseded by README) |
| `LITEBROWSER3_OVERVIEW.md` | 3.0 | Legacy 3.0 overview (superseded) |
| `BROWSER_FULL_SYSTEM_REPORT.md` | 3.0 | Ultra-detailed 3.0 report: features, architecture, module links, data flow |
| `BROWSER_FEATURE_AUDIT.md` | 3.0 | Audit of features, bugs, redundant parts, and messy code areas |
| `ANDROID_BRIDGE_SPEC.md` | planned | Design spec for a future Android remote-manager/data-bridge app (LAN + shared token); not yet implemented |

If you need any of these translated to English or rewritten against the current 6.x codebase,
open a follow-up task for that specific file.
